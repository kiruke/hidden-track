# Hidden Track

最後の一曲は、まだ知らない。

## 概要

Hidden Trackは、最後に隠された一曲が自動再生される、公開プレイリストアプリです。

CD時代の隠しトラックのように、聴き終わったと思った後に予期しない楽曲と出会う体験をWeb上で再現することを目指します。

## コンセプト

- 誰でも公開プレイリストを閲覧・視聴できる
- 作成者は好きな楽曲を選び、再生順を決められる
- 最後の一曲を隠しトラックとして設定できる
- 隠しトラックは通常のプレイリスト一覧に表示されない
- 通常曲を最後まで再生すると、隠しトラックが自動的に流れる
- 隠しトラックは再生が始まるまで曲名を明かさない

## 想定するユーザー体験

1. ユーザーが公開プレイリストを作成する
2. YouTubeの楽曲動画を検索・登録する
3. 通常曲の再生順と隠しトラックを設定する
4. 公開URLを通じて誰でもプレイリストを視聴できる
5. 通常曲が順番に再生される
6. 最後の通常曲の再生終了後、隠しトラックが自動的に再生される
7. 隠しトラックの再生開始時に曲名を公開する

## 技術構成（候補）

- Ruby on Rails
- PostgreSQL
- JavaScript / Stimulus
- YouTube IFrame Player API
- YouTube Data API（楽曲検索）

技術構成は検証後に確定する。

## 技術的な検証課題

### 連続再生

- YouTube動画を指定した順番で再生できるか
- 動画終了イベントを正しく検知できるか
- 次の動画をユーザー操作なしで再生できるか
- ChromeやSafariなどのブラウザで動作するか

### 隠しトラック

- 隠しトラックの動画IDや曲名を再生前にブラウザへ渡さない
- 最後の通常曲の終了後にRailsから動画IDを取得する
- 取得した動画を自動再生できるか
- 再生開始まで曲名を公開しない
- 再生終了イベントの偽装による不正な公開への対応を検討する

### YouTubeの制約

- 埋め込みプレーヤーを規約に従って表示する
- 広告や動画読み込みによる再生の中断を考慮する
- 自動再生制限に対応する
- 埋め込み禁止動画や削除済み動画を考慮する
- YouTube APIの利用規約とクォータを確認する

## MVP（最小実装）

- プレイリスト作成
- YouTube動画の登録
- 曲順の設定
- 隠しトラックの設定
- 公開プレイリストの閲覧
- 通常曲の連続再生
- 最後の通常曲終了後の隠しトラック自動再生

## 未決定事項

- 通常曲終了後に無音時間を設けるか
- 一度公開した隠しトラックを再訪時に表示するか
- プレイリストの作成・編集にログインを必須とするか
- 曲数の上限
- スキップ時の隠しトラック解放条件
- 再生履歴の保存方法
